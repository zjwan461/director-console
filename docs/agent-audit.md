### 1.2 剪辑页有、助手够不着的（关键缺口）

| 能力 | 剪辑页 | 助手 |
|---|---|---|
| 批量写字幕 / 旁白 | ✅ AI 剪辑 | ❌ 无工具 |
| 配音（TTS）+ 自动调速 | ✅ | ❌ |
| 分段配乐 / 选 BGM | ✅ | ❌ |
| 转场类型 / 画幅 / 帧率 | ✅ 成片设置 | ❌（导出只能选分辨率） |
| 片头片尾文案 | ✅ | ❌ |
| 节奏检查 | ✅ | ❌ |
| 新建项目 | ✅ 项目页 | ❌（会话必须先绑定已有项目） |
| 加空镜头 / 调整顺序 | ✅ | ❌ |
| 撤销 AI 改动 | ✅ 有 undo 快照 | ❌ |

**结论：目前是「自然语言生成」，还不是「自然语言剪辑」。**
一句话做不到「帮我做三镜短片，配旁白和字幕，加轻快音乐，导出竖屏」——需要 8 次以上手动操作。

## 三、可优化的点

### 3.1 交互
1. **右栏画布升级为「任务中心」**：当前在跑 / 排队 / 最近产物，带取消按钮。
2. **确认卡支持「再来一次，但换…」**：现在只有执行/取消。
3. **产物卡加操作**：存镜头、再生成一次、作为首帧做视频（一步到位）。
4. **失败卡带重试**：现在只能重发消息。

### 3.2 性能
1. **图片生成完成到消息出现有 3 秒轮询延迟**（`watch_job` interval），可改成 ComfyUI 事件推送。
2. **chat 走两次模型**（decide + 流式回答），可合并为一次流式调用 + 后置意图标注。
3. **env_check 每次读全部能力卡**，可缓存 60 秒。

### 3.3 稳定性
1. **checkpoint 落库**（`AsyncSqliteSaver`）替代 MemorySaver，重启也能续确认。
2. **AI 剪辑失败镜头重试**已有；缺「跳过并继续」。
3. **统一任务中心**：`jobs` / `renders` / `agent_runs` / `ai_edit_runs` 四条状态流合并成一个视图。

## 七、任务页合并（2026-10-26 晚）

原来「任务中心 + 原任务列表」两个列表并存，同一个任务出现两次、两套操作。现已合并为一个：

- 删掉 `JobsPanel`，`/api/tasks` 成为唯一数据源
- 支持 **分页**（每页 20，上一页/下一页，越界自动回退）
- 筛选：类型（生成/成片/助手/剪辑，带数量）+ 状态（进行中/已完成/失败）
- 每行操作：取消 / 重试 / 产物预览 / 打开对应页面
- 查询参数：`kind`、`status`、`limit`、`offset`，返回 `total`、`counts`、`active`

实测：318 条任务，第 1 / 2 页各 20 条，无重叠。

## 九、Step 1：状态与修订（2026-10-26 晚）

**状态升级**：线程不再只记 `last_asset`，而是「产物列表 + 编号 + 血缘」。

- `agent/state.py`：产物按时间编号（#1、#2…），记录 `params` / `parent_ref` / `note`
- 指代解析：`第 2 张`、`刚才那个`、`上一版`、`上次那个`、`雪地里的白狐那张`、`第 2 镜`
- 修订动作：`revise` → 抽参数差异（亮度/速度/画幅/时长/清晰度）→ 基于目标版本重跑
- 确认卡显示差异：`基于 #1 · 追加描述：整体更明亮…`，前端产物卡显示 `#1` 与 `改自 #1`

**顺带修掉的结构性问题**

- `prepare_*` 全部改条件边：预览失败走 `quick_reply` 秒回，不再硬弹空确认卡
- 疑问句在短路之前判定：`你有哪些视频工作流` 不再被「视频+最近产物」抢走
- 新增 `quick_reply` 节点：错误提示/澄清不调模型，0.1s 返回
