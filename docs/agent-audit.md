# 导演助手 · 全局体检（2026-10-26）

> 目标对齐：**用自然语言完成「出图 → 出视频 → 剪辑 → 出片」全流程**。
> 这份文档按「能做什么 / 缺什么 / 有什么坑 / 怎么补」四段给出结论，并标注证据。

## 一、能力现状

### 1.1 已经能纯自然语言完成

| 能力 | 触发方式 | 状态 |
|---|---|---|

| 文生视频 | 「做一个 5 秒…视频」 | ✅ 确认卡 + 时长/画幅/清晰度 |
| 图生视频 | 出图后说「可以/就用这张」 | ✅ 自动带首帧 |
| 参考生视频 | 「参考这张图…」 | ⚠️ 有 r2v 卡片，但意图识别只走 i2v |
| 查素材 | 「素材库里有什么猫的图」 | ✅ 返回缩略图卡片 |
| 导出成片 | 「导出成片」「导出 1080p」 | ✅ 读剪辑页状态渲染 |
| 存为镜头 | 「存成镜头」「放进项目」 | ✅ 图片卡会被拒绝并提示 |
| 多轮承接 | 「可以」「开始吧」 | ✅ 规则短路，不走模型 |
| 会话管理 | 新建/改名/自动起名 | ✅ |
| 刷新恢复 | —— | ⚠️ 刷新 OK，**服务重启后确认失效**（已改为明确报错） |

### 1.2 剪辑页有、助手够不着的（关键缺口）

| 能力 | 剪辑页 | 助手 |
|---|---|---|
| 批量写字幕 / 旁白 | ✅ AI 剪辑 | ❌ 无工具 |
| 配音（TTS）+ 自动调速 | ✅ | ❌ |
| 分段配乐 / 选 BGM | ✅ | ❌ |
| 转场类型 / 画幅 / 帧率 | ✅ 成片设置 | ❌（导出只能选分辨率） |
| 片头片尾文案 | ✅ | ❌ |
| 节奏检查 | ✅ | ❌ |
| 新建项目 | ✅ 项目页 | ❌（会话必须先绑定已有项目） |
| 加空镜头 / 调整顺序 | ✅ | ❌ |
| 撤销 AI 改动 | ✅ 有 undo 快照 | ❌ |

**结论：目前是「自然语言生成」，还不是「自然语言剪辑」。**
一句话做不到「帮我做三镜短片，配旁白和字幕，加轻快音乐，导出竖屏」——需要 8 次以上手动操作。

## 三、可优化的点

### 3.1 交互
1. **右栏画布升级为「任务中心」**：当前在跑 / 排队 / 最近产物，带取消按钮。
2. **确认卡支持「再来一次，但换…」**：现在只有执行/取消。
3. **产物卡加操作**：存镜头、再生成一次、作为首帧做视频（一步到位）。
4. **失败卡带重试**：现在只能重发消息。

### 3.2 性能
1. **图片生成完成到消息出现有 3 秒轮询延迟**（`watch_job` interval），可改成 ComfyUI 事件推送。
2. **chat 走两次模型**（decide + 流式回答），可合并为一次流式调用 + 后置意图标注。
3. **env_check 每次读全部能力卡**，可缓存 60 秒。

### 3.3 稳定性
1. **checkpoint 落库**（`AsyncSqliteSaver`）替代 MemorySaver，重启也能续确认。
2. **AI 剪辑失败镜头重试**已有；缺「跳过并继续」。
3. **统一任务中心**：`jobs` / `renders` / `agent_runs` / `ai_edit_runs` 四条状态流合并成一个视图。

## 四、建议路线

### P0（先让"能停、能看、能改"闭环，约 1 天）

1. **取消运行**：agent run + ai_edit run 都加 cancel（前端按钮）
2. **导出前清单**：确认卡显示「3 镜 / 烧字幕 / 2 条 BGM / 片头 1.5s」
3. **失败卡带「重试」**
4. **图片/视频完成后产物卡直接给「存镜头」「做视频」两个按钮**

### P1（补上"剪辑"这一半，约 3 天）

5. **助手调用 AI 剪辑**：新增工具 `polish_film(kinds)`，内部走 `ai_edit.start`，进度用同一 SSE
6. **BGM 工具**：`set_bgm(mood|asset|auto)` → 写 `edit_state.options.bgm_tracks`
7. **成片设置工具**：`set_film_options(transition, title, tail, aspect)`
8. **建项目 / 加镜头**：`create_project`、`add_shot`
9. **统一任务中心**（前端一个面板看全部在跑的东西）

### P2（提升质量，按需）

10. 持久化 checkpoint（重启可续）
11. 一句话多镜编排（"三镜：开场…发展…收尾…"）
12. 成本与限流（每会话每日任务数、并发上限）
13. 会话上下文升级为「产物列表 + 镜头引用」

### 回归结果

```
全链路 18/18 通过
R1 素材检索   R2 出图(参数生效)  R3 图生视频(可以)  R4 图片卡存镜头被拒
R5 导出清单   R6 AI 剪辑(启动/取消)  R7 配乐写入  R8 标题/改名
R9 取消运行   R10 项目隔离

视频链路 9/9 通过
文生视频(3s) → 存为镜头 → 导出 720p（3.1s 成片）
```

修复的回归问题：
1. 「画一张…竖屏」被成片设置抢走 → 意图优先级改为 肯定回复 > 关键词语义 > 模型
2. 「可以，就用这张图」在产物上下文落库前抢跑 → 从 artifact 兜底取首帧素材

## 六、一句话结论

- **生成侧已经可用**：出图、出视频、改参数、导出、存镜头，都能一句话完成。
- **剪辑侧已打通**：字幕、旁白、配音、配乐、转场、片头片尾都能一句话完成（P1）。
- **稳定性刚补到"重启会明确报错"**，再往上要落库 checkpoint。
- 下一步建议：**从零建项目/加镜头**、**统一任务中心**、**checkpoint 落库**。
