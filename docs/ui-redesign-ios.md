# 前端视觉重设计 · 显色 / iOS 语言 / 全局动效

> 目标：从「深色工具后台」改成**显色、有材质、有节奏**的创作工作台。
> 约束：**不改后端功能**；只做视觉与交互层，必要时微调前端请求（如骨架屏的加载态）。

---

## 一、设计定位

| 维度 | 现在 | 改后 |
|---|---|---|
| 气质 | 深色 IDE，信息密度高但冷 | 深色 + 高饱和色彩点缀，像 iOS 深色模式的「专业 App」 |
| 色彩 | 单一靛蓝 accent | **六色系统色**：蓝/紫/粉/橙/绿/青，按语义分配（生成/剪辑/配乐/导出/成功/提示） |
| 材质 | 纯色面板 + 1px 描边 | **半透明毛玻璃**（backdrop-blur）+ 双层高光边 |
| 圆角 | 10–14px | **18–28px**（卡片 22、按钮 14、胶囊 999） |
| 阴影 | 几乎没有 | 柔和多层阴影 + 彩色泛光（按主色 tint） |
| 动效 | hover 变色、active 位移 1px | **弹簧进场、逐条错峰、图标回弹、进度流光、数字滚动** |

## 二、色彩系统（CSS 变量）

```
/* 系统色（iOS 深色模式基准，略提高饱和） */
--sys-blue:    #0A84FF
--sys-purple:  #BF5AF2
--sys-pink:    #FF375F
--sys-orange:  #FF9F0A
--sys-green:   #30D158
--sys-teal:    #64D2FF
--sys-yellow:  #FFD60A
--sys-gray:    #8E8E93

/* 语义映射 */
--c-generate: var(--sys-blue)     出图 / 出视频
--c-edit:     var(--sys-purple)   剪辑 / 修订
--c-audio:    var(--sys-orange)   配乐 / 旁白
--c-export:   var(--sys-green)    导出 / 成片
--c-danger:   var(--sys-pink)     删除 / 失败
--c-info:     var(--sys-teal)     提示 / 状态
```

背景：深灰底 `#0B0C10` + 两团低透明度彩色光晕（蓝/紫），随 tab 切换缓慢位移。

## 三、排版

- 字族：`-apple-system, "SF Pro Text", "PingFang SC", "Segoe UI", sans-serif`
- 尺寸阶：11 / 12 / 13 / **15（正文）** / 17（小标题）/ 22（标题）/ 28（大标题）
- 字重：正文 400，标签 500，标题 600，数字 600 + `font-variant-numeric: tabular-nums`
- 行高：正文 1.55，标题 1.25

## 四、组件规范

### 1. 侧边导航（rail）

- 悬浮岛式：`margin: 14px`，圆角 28，毛玻璃，右侧留 1px 高光
- 每项：图标（SF Symbols 风格线性图标，20px）+ 文案 + 选中态胶囊
- 选中态：底色 = 该项语义色 12% 透明 + 左侧 3px 竖条渐变 + 文字变白
- 切换：胶囊用 `spring` 位移（transform translateX），图标 `scale(1.08)` 回弹
- 角标：红点带脉冲（`@keyframes pulse`）

### 2. 顶部标题区

- 大标题 28/600 + 副标题 13/muted
- 滚动时标题区收缩（`position: sticky` + 高度动画）

### 3. 卡片

- 圆角 22，背景 `rgba(255,255,255,.045)` + `backdrop-filter: blur(20px)`
- 边框 `1px solid rgba(255,255,255,.08)`，内阴影 `inset 0 1px 0 rgba(255,255,255,.06)`
- 悬停：上浮 2px + 阴影加深（`transition: .25s cubic-bezier(.2,.8,.2,1)`）
- 选中：外发光 `0 0 0 1px var(--c-*)` + `0 8px 30px rgba(彩,.18)`

### 4. 按钮

| 类型 | 样式 |
|---|---|
| primary | 语义色渐变 + 白色文字 + 彩色泛光阴影，按下 `scale(.97)` |
| secondary | 半透明底 + 1px 边，按下 `scale(.98)` 且底色变深 |
| ghost | 无底，hover 出现 8% 白底 |
| 危险 | 粉色文字 + 粉色 12% 底 |

所有按钮：`transition: transform .12s ease, background .2s, box-shadow .25s`。

### 5. 输入框

- 圆角 14，底色 `rgba(255,255,255,.05)`，聚焦时 2px 语义色描边 + 4px 光晕
- 文本域右下角显示字数/预计时长

### 6. 加载态（关键：不许傻等）

| 场景 | 方案 |
|---|---|
| 列表/网格首次加载 | **骨架屏**（shimmer 流光），形状与真实内容一致 |
| 生成任务 | 卡片内**进度流光条** + 预计秒数倒计时 + 阶段文案（排队→上传→采样→下载） |
| 单次请求 | 按钮内旋转小圈，按钮宽度不变 |
| 长文本生成 | 打字机光标 + 「思考中」呼吸点 |

### 7. 空状态

- 居中插画位（emoji 或线性图标）+ 一句说明 + 一个主行动按钮
- 例：资产页空 → 「还没有素材 · 去创作台出一张」

### 8. 弹层 / 对话框

- iOS sheet 风格：底部滑入，圆角 28，顶部有拖拽条
- 遮罩 `rgba(0,0,0,.5)` + `backdrop-blur(8px)`
- 关闭：向下拖或点遮罩，带惯性

## 五、动效系统

```
--ease-spring: cubic-bezier(.22,1.2,.36,1);
--ease-out:    cubic-bezier(.2,.8,.2,1);
--dur-fast: .16s;  --dur-mid: .28s;  --dur-slow: .48s;
```

| 动效 | 用法 |
|---|---|
| `page-in` | 切 tab：内容 `opacity 0→1` + `translateY(8px→0)` + `scale(.995→1)` |
| `stagger` | 列表项 `animation-delay: i*40ms` |
| `pulse` | 角标、进行中圆点 |
| `shimmer` | 骨架屏、进度条 |
| `press` | 按钮 `:active { scale(.97) }` |
| `float` | 卡片 hover 上浮 |
| 减少动效 | 尊重 `prefers-reduced-motion` |

## 六、逐页改造清单

### 创作台（studio）
- 能力卡：从「列表行」改成**两列卡片网格**，每张卡左侧语义色竖条 + 图标；hover 上浮
- 表单：分组标题（画面 / 参数 / 参考图），参数用胶囊 chip 选择
- 右侧「生成」按钮：吸底，显示预计耗时与消耗

### 剪辑（edit）
- 分镜条：横向胶片，每镜缩略图 + 序号 + 时长，选中放大 1.04 + 彩色描边
- 时间轴：轨道颜色区分（画面/旁白/字幕/BGM）
- 播放头：拖动时有磁吸与刻度

### 资产 / 成片 / 任务
- 网格卡片：图片 `object-fit: cover` + 悬停放大 1.03 + 底部渐变信息条
- 任务行：状态用**彩色圆点 + 流光进度**；失败行淡红底

### 导演助手（agent）
- 消息气泡：助手侧毛玻璃，用户侧语义色渐变
- 过程块：折叠时一行「过程 · 3 步 · 进行中·看图写运镜」，展开逐条错峰
- 生成中：气泡内三点呼吸 + 进度条

6. 逐页截图对比，按你的反馈微调

## 八、验收标准

- 首屏 1 秒内出现骨架，不出现纯空白等待
- 每次点击都有可见反馈（≤120ms 内）
- 切换 tab 有过渡，不闪白
- 深浅对比符合 WCAG AA（正文对比度 ≥ 4.5）
- `prefers-reduced-motion` 下动效降级
